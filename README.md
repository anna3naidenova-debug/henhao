# Сайт школы китайского Hěn hǎo

Одностраничный сайт на чистом HTML/CSS/JS. Без сборки, без внешних CDN и без Google: сайт должен открываться из Китая без VPN.

## Что где лежит

```
site/                    ← это и есть сайт (папка для публикации)
  index.html             главная страница
  site.config.js         ★ ВСЕ цены, флаги, контакты, слова, FAQ, варианты формы
  404.html               страница ошибки
  privacy.html, consent.html, offer.html, requisites.html — юридические документы
  legal-manifest.json    версии и хеши документов
  assets/css/style.css   стили
  assets/js/main.js      логика: кинетика, тарифы, форма, QR, часы
  assets/js/qrcode.js    генератор QR (MIT, лежит локально)
  assets/fonts/          шрифты-сабсеты woff2
  assets/img/            гуси, логотип, OG-картинка, фавиконы
netlify/functions/lead.mjs  старый endpoint отключён (410), заявки принимает server.mjs
lib/lead-store.mjs        запись заявки с согласием и защита от повторов
tools/build_legal.py      DOCX → HTML без переписывания текста
tools/check_legal.py      сверка HTML с оригиналами
tests/                   серверные тесты без отправок в рабочий Telegram
netlify.toml             настройки Netlify (не используются)
server.mjs               сервер на Amvera: сайт + приём заявок → файл /data и Telegram
tools/subset_fonts.py    пересборка шрифтов
tools/fonts-src/         исходные шрифты (на сайт не попадают)
tools/cutouts/           PNG-вырезки гусей и логотипа
```

## Как посмотреть локально

Самое простое — открыть `site/index.html` двойным кликом.
Надёжнее (как на хостинге) — запустить мини-сервер в терминале:

```
cd site
python3 -m http.server 8000
```

и открыть http://localhost:8000

Через `python3 -m http.server` форма не работает (нет `/api/lead`), для проверки формы запускайте `node server.mjs`, см. ниже. Если поставить `form.demoMode: true`, форма ничего не отправляет и сразу показывает экран успеха — на сайте так не оставлять.

## Как поменять цены, тексты, контакты

Всё в `site/site.config.js`. Например:

- цены (в рублях) — `tariffs[].price` (первый поток), цена следующего потока — `tariffs[].nextPrice`;
- строка «со следующего потока — … ₽» — `flags.showStrikePrice` (`false` — скрыть);
- тарифы «С носителем» — `flags.showNative`. Если носителя к запуску нет, поставьте `false` — обе карточки скроются;
- блок встречи — `flags.showMeetup: true` и заполнить `meetup.date` и `meetup.place`;
- блок преподавателей — `flags.showTeacher: true`, данные карточек в массиве `teachers`. Поля: `name`, `role`, `language`, `groups` (направления), `experience`, `photo`; `highlight` — акцент на фото, `credential` — образование или ключевая квалификация. Поля `about` и `advice` открываются в боковой панели по кнопке «О преподавателе». Фото положить в `site/assets/img/teachers/` и указать путь вроде `assets/img/teachers/shuo.jpg` в `photo`. Пустые фото, опыт и направления показывают заглушки;
- QR из WeChat — положить картинку в `site/assets/img/wechat-qr.png` и вписать путь в `contacts.wechatQr`;
- Аналитика отключена. `metrikaId` не запускает счётчик. Перед будущим подключением нужны выбор пользователя, отложенная загрузка до согласия, сохранение и изменение выбора, остановка аналитики при отзыве и обновление Политики. Точка подключения для целей — `window.henhaoAnalytics.goal(name)`: адаптер можно устанавливать только после соответствующего выбора пользователя. Сейчас адаптер и внешние скрипты отсутствуют.

**Если добавили новый иероглиф** (в конфиг или в HTML) — пересоберите шрифты, иначе он отобразится системным шрифтом:

```
pip3 install fonttools brotli
python3 tools/subset_fonts.py
```

## Где работает сайт и заявки в Telegram

Сайт https://henhaoschool.ru размещён на Amvera и обновляется сам после каждого push в ветку `main` (подробно в `HOSTING.md`).

- Заявки формы принимает `server.mjs` по адресу `/api/lead`, сохраняет копию каждой заявки в файл `/data/leads.jsonl` на Amvera (раздел «Данные» проекта) и пересылает в Telegram.
- Токен бота и chat id заданы в Amvera → «Переменные» (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`), в репозиторий их не добавлять.
- В `site/site.config.js` у формы должно оставаться `demoMode: false` и `endpoint: "/api/lead"`.
- Не удалять `server.mjs`, `package.json`, `amvera.yml`. Папка `netlify/` и `netlify.toml` не используются.
- Локально форму можно проверить так: `PORT=8080 LEADS_FILE=/tmp/leads.jsonl node server.mjs` и открыть http://localhost:8080 (без переменных Telegram заявка только запишется в файл).

## Юридические документы и согласия

Документы доступны без авторизации: `/privacy.html`, `/consent.html`, `/offer.html`, `/requisites.html`.
Исходные DOCX находятся в корне проекта. Тексты и нумерация сохраняются полностью.

```
python3 tools/build_legal.py
python3 tools/check_legal.py
npm test
```

При новой редакции необходимо одновременно обновить дату/версию в генераторе и атрибуты
`data-consent-version` / `data-consent-document-id` и `data-privacy-version` / `data-privacy-document-id` формы, пересобрать страницы и перезапустить сервер.
Проверка `check_legal.py` выявляет рассогласование формы и документов. Сервер отказывается запускаться,
если хеш страницы согласия отличается от манифеста. Архивируйте прежние редакции документов до замены:
хеш в записи согласия должен позволять сопоставить запись с сохранённым текстом.

`/api/lead` принимает строго `consent: true`, идентификатор и текущую версию документа,
UUID v4 `request_id`, отдельное `privacy_acknowledged: true` с актуальными ID/редакцией Политики и валидные контакты. В `/data/leads.jsonl` одной строкой сохраняются
заявка, серверный `lead_id`, ключ повтора, хеш данных и объект `consent`: `consent_id`,
`event_id`, `lead_id`, `document_id`, `document_version`, `document_sha256`,
`accepted`, `checkbox_checked`, метод и серверное время `recorded_at` (ISO 8601, UTC).
Время браузера хранится отдельно и не используется как время согласия.
Отдельный объект `privacy_acknowledgement` фиксирует ознакомление с Политикой:
свой UUID события, связь с заявкой, ID/редакцию/хеш документа, отметку и серверное время UTC.
Это самостоятельный чекбокс «Ознакомлен с политикой обработки персональных данных»;
он не заменяет согласие и не включается в Telegram-уведомление.

Запись сбрасывается на диск до положительного ответа. Повтор с тем же ключом и данными не
создаёт новую запись/уведомление; другой состав данных с тем же ключом даёт 409.
Индекс восстанавливается из файла при перезапуске; старые строки без согласий сохраняются.
Хранилище рассчитано на **один процесс/одну реплику**, как текущий `node server.mjs`.
Для нескольких реплик нужна общая транзакционная БД с уникальным ключом запроса.
Повреждённый/незавершённый журнал блокирует новые записи до ручного восстановления
из резервной копии: автоматически удалять или исправлять строки сервер не будет.
Файл находится вне `site/`, права — 0600; новый каталог — 0700.

В Telegram передаются контакты и прежние данные заявки, а также напоминание менеджеру
о документах и индивидуальных условиях до оплаты. Технический объект согласия туда не уходит.
Три попытки уведомления сохранены. Если Telegram недоступен, заявка остаётся на сервере;
долговременной очереди повторной доставки уведомлений нет. Контролируйте сообщения
`Telegram: ... failed; lead saved` и сверяйте их с серверным журналом.

Успех интерфейса показывается только после ответа `{ok:true}`. При ошибке поля сохраняются,
кнопка становится доступна, повтор использует прежний ключ, двойной клик блокируется.
Чекбокс очищается при восстановлении страницы и при открытии формы после успешной заявки.
Идентификатор повтора живёт в памяти вкладки: перезагрузка/новая вкладка начинает новое обращение.

Автоматическое удаление старых заявок не включено, чтобы не удалять существующие данные.
Оператору необходимо организовать учёт последнего обращения, договорного статуса,
отзывов и сроков хранения из Политики (в том числе в переписке и резервных копиях).
Сайт не может проверить эти организационные действия или настройки сторонних сервисов.
